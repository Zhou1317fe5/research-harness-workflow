# 日常实验使用指南：双会话协作与 CSV 执行

项目接好工作流后，一轮标准实验建议采用**“双会话解耦”**模式：一个会话用高级模型专注方案设计，另一个会话用高配额模型专注任务执行。

还没有接入项目的话，先看[项目适配协议](agent-onboarding.md)。

---

## 核心工作流：双会话分工

```text
【会话 1：方案讨论会话】
模型：高级强模型（如 gpt-6-astra / gpt-6.1-sol）
动作：讨论科研假设与基线对照 → 生成 Spec → 审阅确认 → 生成任务 CSV
                              ↓
                      输出 issues/.../*.csv
                              ↓
【会话 2：任务执行会话】
模型：执行模型 / 高额度模型（如 gpt luna / deepseek）
动作：直接输入 mission issues/<任务目录>/<任务清单>.csv
     代码实现 → 运行前审查 (PRERUN) → 托管训练 (rrctl) → 证据拉回与分析
```

> **注意**：已不再使用任何 `goal` 模式或插件（Pi 用户无需安装 `@narumitw/pi-goal`，已有可直接卸载）。任务进度、执行状态与断点恢复完全由任务 CSV 自身驱动。

---

## 一、方案讨论与生成 Spec（强模型会话）

先开启一个独立的会话，配置更具推理能力的强模型（如 `gpt-6-astra`、`gpt-6.1-sol`）。

输入研究意图，让模型读取当前基线与实验现状：
```text
mission 我想在现有基线上验证一种新采样策略。

先读取当前研究状态和已有基线结果。
本轮只改采样策略，沿用网络结构、数据划分和评测口径。
请和我讨论对照怎么做、主指标怎么看、需要多少运行预算，以及什么情况下停止。
先形成实验方案，暂不实现和启动训练。
```

方案讨论的核心是**定死标准**：
- 明确要回答的科学问题；
- 明确跟哪个基线在什么相同协议下对比；
- 明确主指标达到多少算成功，什么结果算失败该停。

共识达成后，让 Agent 将方案写入 Spec 文件（存放在 `docs/specs/`）。

---

## 二、审阅 Spec 并转成任务 CSV

人工通读生成的 Spec 文档，重点检查假设、对照设置、指标阈值和验收要求。

确认无误后，指令其生成执行清单：
```text
批准这份方案。
请保存批准状态并提交方案，再用 mission 生成对应的任务 CSV。
这一步做到 CSV 准备完成即可。
```

Agent 会在 `issues/<任务目录>/` 下生成专属的任务清单 CSV，并输出该 CSV 的文件路径。方案阶段到此结束。

---

## 三、执行任务 CSV（执行模型新会话）

开启一个**全新的执行会话**，切换为成本更低、额度充裕的执行模型（如 `gpt luna`、`deepseek`）。

无需使用 goal 模式，直接输入该 CSV 路径开始执行：
```text
mission issues/<任务目录>/<任务清单>.csv
```

执行模型接下来会按清单逐行推进：
1. **代码修改与本地轻量验证**：检查参数传递链路、输入输出格式及语法正确性。
2. **短运行与实施审查**：改动模型、损失或数据等核心逻辑时，先跑 1~100 步短 smoke，并通过只读 fresh 会话做 PRERUN 审查。
3. **远程提交与首步检查**：通过 `rrctl` 提交 GPU 运行，并在 30 秒至 2 分钟内严格核对显存、step >= 1 和有限 Loss。

---

## 四、训练等待与状态托管

长训练由 `rrctl` 的独立进程后台全程托管，Agent 无需以定时轮询读日志打扰用户：
- 首步验证通过后，Agent 进入静默等待状态。
- 训练完成后自动唤醒，接续执行原 CSV 清单；运行失败时调阅诊断日志。

---

## 五、暂停与断点恢复

如果中途会话中断、网络断开或需要暂停：
- **查看与继续**：新开执行会话后，直接再次输入：
  ```text
  mission issues/<任务目录>/<任务清单>.csv
  ```
  或者仅输入 `mission`，Agent 会自动从 `issues/.missions.json` 读取当前活跃任务指针，沿 CSV 中未完成的任务行精准恢复，绝不重复启动已完成的实验。

---

## 六、结果查阅与收尾

训练全部结束后，Agent 自动拉回结果摘要并生成结论，用户可查阅以下位置：

| 想看什么 | 位置 |
|---|---|
| 当前全局研究主线 | `research_workspace/STATE.md` |
| 已验证的有效结论 | `research_workspace/CONCLUSIONS.md` |
| 已有实验索引台账 | `research_workspace/EXPERIMENTS.csv` |
| 本次实验事实与分析 | `research_workspace/experiments/<ExpID>/analysis/analysis.md` |
| 本轮执行交付与交接记录 | `issues/<任务目录>/` |
| 远端拉回的原始运行证据 | `remote_artifacts/<ExpID>/<RunID>/` |
